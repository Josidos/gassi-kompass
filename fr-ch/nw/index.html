Règles pour les chiens dans le canton de Nidwald

Ces règles valent dans toutes les communes du canton de Nidwald. Les communes peuvent désigner d'autres lieux où la laisse est obligatoire ou les chiens interdits.

Traduction de l'allemand. Les sources officielles sont en allemand. Version originale en allemand

Laisse en forêt · Canton de Nidwald

Pas de période fixe en forêt

Le Hundegesetz (loi sur les chiens) et la Jagdverordnung (ordonnance sur la chasse) du canton ne prévoient pas de laisse obligatoire en forêt à des dates fixes. Vous ne pouvez toutefois laisser votre chien courir librement sans surveillance nulle part. Dans les zones de tranquillité pour la faune, la Verordnung über die Wildruhegebiete (ordonnance sur les zones de tranquillité pour la faune) prévoit la laisse obligatoire pour les chiens (état de l'ordonnance : 2019). Sur place, observez les panneaux. Les chiens qui rôdent sans surveillance dans les zones de refuge du gibier ou qui poursuivent, traquent ou tuent du gibier sont considérés comme braconnant et peuvent être abattus par les gardes-faune.

Sources :Hundegesetz NWJagdverordnung NWVerordnung Wildruhegebiete NW

Pas de laisse obligatoire saisonnière dans le canton de Nidwald

Laisse et accès dans le canton de Nidwald

LaisseToujours en laisse

  • sur les terrains de sport et dans les installations scolaires (Hundegesetz, version de 2005)
  • dans les zones de tranquillité pour la faune, dans la mesure où la Verordnung über die Wildruhegebiete le prévoit (état 2019)
  • partout où le Regierungsrat (gouvernement cantonal) a ordonné la laisse ou la muselière obligatoire
  • si le vétérinaire cantonal l'ordonne pour votre chien dans un cas particulier
Sources :Hundegesetz NWVerordnung Wildruhegebiete NW

InterditAccès interdit aux chiens

Le Hundegesetz interdit d'emmener des chiens dans ces lieux ou de les y laisser courir (version de 2005). L'amende d'ordre est de CHF 100.

  • les cimetières
  • les places de jeux
  • les plages de baignade
Sources :Hundegesetz NWOrdnungsbussenverordnung NW

Obligations des détenteurs de chiens dans le canton de Nidwald

Responsabilité civileHundegesetz

non mentionnée dans le Hundegesetz

Dans la version consultée (en vigueur depuis 2005), le Hundegesetz du canton ne contient aucune disposition sur une assurance responsabilité civile. La page du contrôle des chiens ne mentionne pas non plus d'obligation d'assurance.

Sources :Hundegesetz NWAmt für Justiz NW: Hundekontrolle
CoursCas particulier

seulement sur ordre

Le Hundegesetz ne prévoit pas d'obligation générale de suivre un cours (version de 2005). Après une morsure, une menace ou en cas de comportement anormal, le vétérinaire cantonal peut ordonner de suivre un cours d'éducation.

Sources :Hundegesetz NWKanton NW: Gefährliche Hunde
AnnonceObligatoire

Amt für Justiz, dans les 3 mois après la naissance

Vous annoncez votre chien à l'Amt für Justiz (office cantonal de la justice), au plus tard trois mois après la naissance. Cela se fait au moyen du formulaire en ligne «Anmeldung Hund» (annonce d'un chien). L'office vous enregistre dans la banque de données AMICUS. Le chien porte une puce électronique. Vous annoncez à l'office tout changement de nom ou d'adresse dans les 10 jours. Amende d'ordre en cas d'obligation d'annonce non remplie ou d'identification manquante : CHF 100 dans chaque cas.

Sources :Amt für Justiz NW: HundekontrolleHundeverordnung NWOrdnungsbussenverordnung NW
Impôt sur les chiensCanton

CHF 120 par an

L'impôt sur les chiens est de CHF 120 par année civile dans tout le canton. L'Amt für Justiz le taxe et le perçoit. Si vous partez ou si votre chien meurt, l'impôt peut vous être remboursé au prorata, sur demande.

Source :Amt für Justiz NW: Hundekontrolle
RacesCas particulier

aucune liste mentionnée

Ni le Hundegesetz (version de 2005) ni la page du canton sur les chiens dangereux ne mentionnent de races de chiens. Les morsures et les menaces dues à des chiens sont annoncées au vétérinaire cantonal. Il peut ordonner des mesures, par exemple la laisse ou la muselière obligatoire ou une interdiction de détention. L'élevage visant l'agressivité est interdit.

Sources :Hundegesetz NWKanton NW: Gefährliche Hunde
En promenadeRègle

ramasser les crottes, surveiller le chien

Vous ramassez les crottes de votre chien sur le domaine public et sur le terrain privé d'autrui et vous les éliminez. Il est interdit de laisser votre chien courir librement sans surveillance. Amendes d'ordre : crottes non ramassées CHF 100, chien pas dûment gardé ou surveillé CHF 100, chien excité intentionnellement CHF 300.

Sources :Hundegesetz NWOrdnungsbussenverordnung NW
